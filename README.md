# Cobblemon Battle Tracker
This **server-side** kubejs and **in-game** computercraft script work together to track and react to conditions of a battle, live. ***You will need console access to set this up***.

To use the scripts **alone**, you'll need the following mods: \\
-> ComputerCraft: Tweaked \\
-> Cobblemon (v1.8.4+)

To use my version of a **battle arena**, you'll also need: \\
-> Create (v6.0+) \\
-> Create Aeronautics \\
-> Chipped
